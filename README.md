# DelayDaemonWin

Im Rahmen der Masterarbeit entwickeltes Programm zum Loggen von Mausevents

## Voraussetzungen

CMake muss installiert sein.

Visual Studio muss installiert sein.

## Steuerung

STRG + ALT + Q: Beendet das Programm 

## Build-Anleitung (Kompilierung)

- Die build.bat kann genutzt werden um den lokalen Build zu erstellen. Die .exe befindet sich dann unter Build/Debug
- Die visualStudio Version muss möglicherweise angepasst werden
